# Oral Temp Predictor
 Testing different machine learning methods (MLP, RNN, Linear Regression) for predicting oral temperature besed on oral readings in a medical setting.
 Data Available from https://physionet.org/content/face-oral-temp-data/1.0.0/, based on paper by Wange et al., (2023) (Available here: https://pubmed.ncbi.nlm.nih.gov/35009758/)
